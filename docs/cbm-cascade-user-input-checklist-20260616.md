## 📋 사용자 작업 — 우선순위 순

- **형식:** `가로x세로x높이` mm (예: `248x190x33`). 2축 `135x195`도 OK(두께 3mm 기본).
- **양식 제공:** `docs/sync_parts_치수입력_worksheet_top100.csv` — 상위 100 PT (차단단위·단독차단·예시굿즈 포함, `규격_입력` 빈칸).
  - **상위 100 PT만 채워도 S3 차단의 ~53%(1069단위) 해소**, 완결률 13.8% → ~40%대 예상.

### 🟡 2순위 — 신규 SKU 박스데이터 (출하 CBM, 진짜 신규 4~5종만)
- **어디:** TMS `Product` (`tblBNh6oGDlTKGrdQ`) → **견적코드** + **박스명칭**(극소형/중형/중대형/대형/특대형) + **박스당 제품수**
  - 박스 CBM은 박스명칭에서 자동(대형=0.1066 등). 원시 m³ 입력 불필요.
- **대상 (sibling 없음 = 진짜 신규):**

  | `UMUG` | 컴포트 스텐머그 | 신규 |
  | `WSPB` | 쇼핑백 | 신규 |

### 🟡 3순위 — ★ 재제작/추가제작 주문 "주문수량=0" 결정 (신규 발견·중요)

- **결정 필요:**
  - (a) 재제작도 실제 생산수량이 있으면 → **order에 주문수량 입력** (그러면 자동 산출)

- 이 한 가지가 "등록코드인데 미산출"의 거의 전부 원인.
