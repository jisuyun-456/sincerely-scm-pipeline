03비유 — 주방으로 보면

NEST는 홀(주문 받는 곳). 요리는 주방(물류)이 한다. 주문서만으로는 요리가 안 된다.

📝 NEST
주문서 — "이 손님이 컬러펜 100개 시켰다". 여기까지가 홀(세일즈)의 일. 이걸론 요리 못 함.
🔤 번역기
메뉴명↔재료명 대조표 — 주문서의 "컬러펜"을 창고 재료명(잉크·펜대)으로 바꿔주는 사전.
📖 Lv3 자재
레시피 — 컬러펜 1개 = 잉크 1 + 펜대 1 + 박스 1. 무슨 재료가 몇 개 드는지의 명세.
🍳 전개엔진
주방 시스템 — 주문 들어오면 레시피 펼쳐 "재료 이만큼 필요·부족분 발주·차는 이걸로" 자동 산출.

04지금 상태 — 제로에서 시작이 아니다

뼈대(전개엔진)는 이미 돌고 있다. 남은 건 데이터 품질과 번역 계층을 채우는 일.

이미 있는 것

  • 전개엔진(cascade) S0~S7 하루 3회 가동 중
  • NEST 수용 — API 검증 완료 (수량 괴리 0% · 키 연결 95.8% · CBM 도달 96.9%)
  • 레벨 구조 확정 — 1,265 프로젝트 전수, L0~L3 4계층 상한 문제없음
  • 크로스워크 테이블·BOM 1,702행 존재

채워야 할 것

  • PT 치수 입력 — 완결률 최대 레버 (S3 입하 CBM 병목)
  • BOM 검증율 7%→↑ · 구성유형 공백 63% 백필
  • 크로스워크 NEST 증거로 채우고 cascade가 읽게
  • NEST에 요구 — 박스스펙 API 노출 · 견적 버전 신호
"세일즈 SSOT(NEST)는 이미 있다. 없는 것은 물류 실행 SSOT — Lv3 + 번역기 + 전개엔진이다. 그걸 우리가 세운다."
