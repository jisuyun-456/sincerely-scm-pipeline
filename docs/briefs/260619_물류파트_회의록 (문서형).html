MEETING MINUTES · INITIATIVE STATUS REVIEW · PMP STANDARD

물류파트 이니셔티브 현황 공유 회의록

WMS Cycle-Time M/H와 BOM·CBM 수량전파 백본 두 이니셔티브의 Phase 1 완료를 공식 확인하고 하반기 로드맵을 정렬한 회의 기록.

회의일자2026.06.19 회의유형이니셔티브 현황 공유 참석자윤지수, 문경선 작성자윤지수

I회의 개요

본 회의는 2026년 6월 19일 금요일 오전, 에이원센터에서 윤지수(물류파트장)와 문경선(물류파트원) 2인 참석으로 진행되었다. 하반기 이니셔티브 2건의 Phase 1 완료 현황을 점검하고, 7월 이후 실행 계획을 정렬하는 것이 목적이었다.

이니셔티브 현황 공유 회의 특성상 이전 회의 Action Items 추적 기록은 없으며, 이번 회의에서 새롭게 확정된 Action Items를 중심으로 기록한다. 회의 시작·종료 시각은 미기재로 추후 보완이 필요하다.

Phase 1 두 이니셔티브 모두 완료 조건을 초과 달성 — 하반기는 실운영 전환과 취약점 해소에 집중한다. 물류파트 이니셔티브 현황 공유 회의, 2026-06-19

III안건별 의사결정

이번 회의에서 2건의 안건을 논의하고 각각 의사결정을 확정하였다.

안건 1 · WMS Cycle-Time M/H Phase 1 완료 및 Phase 2 착수 계획
배경: 기존 CBM 추정 기반 M/H(Man-Hour) 산정 방식은 PT코드별 작업 특성 차이를 반영하지 못해 인원 배치 정확도가 낮았음. 2026년 3월부터 실측 cycle-time 기반 PT코드별 표준 M/H 전환 이니셔티브를 착수, Phase 1(인프라 구축, 3~6월)이 완료됨.

결정: Phase 1 완료 공식 확인. Phase 2(표준 확정, 7~9월)를 2026년 7월부터 착수. 즉시 적용 가능한 PT코드 3개에 대한 선행 운영 적용 검토 진행.

근거 및 기대 효과: 완료 조건(1,000건 이상)을 2,381건으로 초과 달성하여 통계적 신뢰성 확보. Phase 2 목표인 표준 M/H 모델(M/H = setup + qty × rate) 확정을 통해 2026년 9월까지 Top 20 PT코드 기준(입하량 약 70% 커버) 확립. Phase 3(2026년 12월) M/H 기반 인원 배치 자동화 파일럿으로 연결 예정.
안건 2 · BOM·CBM 수량전파 백본 Phase 1 완료 및 하반기 로드맵
배경: Project → Order → Task → PKG → Movement → TMS 6개 모듈 간 자재·패키징 수량 연결이 수동으로 이루어져 오류 및 누락이 발생. 2026년 6월 12일 Phase 1 완료. 그러나 파츠 CBM 미등록 등 4개의 취약점(P0~P3)이 잔존하여 하반기 해소 계획 수립이 필요한 상황.

결정: Phase 1 완료 공식 확인. 즉시 가동 가능한 6개 기능(A2 이송단가 정산, A3 차량적재율 KPI, A4 발송모드 분기, B3 입하예측, C2 패키징소요, D1 출하CBM 사전예측) 운영 시작을 7월 Quick Win으로 지정. P0 취약점(파츠 CBM 미등록) 해소를 8월 최우선 과제로 설정.

근거 및 기대 효과: 굿즈 CBM 커버리지 89.2%로 목표(80%) 초과 달성, Cron 자동화(1일 3회) 가동 중. 추가 개발 불필요한 기능 6건 즉시 운영으로 CBM 기반 Wave 배차 최적화 및 MRP 자동산출 가치를 하반기 실현. 2026년 12월까지 원가분석, 완전주문 파일럿, Lane 수익성, ABC 분석으로 확장 예정.

VIIIPMP 관점 요약

PMP Standard 관점에서 이번 회의의 핵심 내용을 Scope · Schedule · Risk · Financial 4개 영역으로 요약한다.

01
Scope범위 확정

WMS Cycle-Time M/H는 Phase 2(표준 확정 20개 PT코드) → Phase 3(M/H 기반 자동화 파일럿)으로 진행. BOM·CBM 백본은 즉시 가동 6건 + P0~P3 해소 + 10~12월 원가·Lane 분석으로 범위 확장.

02
Schedule일정 기준선

WMS Phase 2 착수: 2026-07 / 완료: 2026-09. WMS Phase 3 파일럿: 2026-12. BOM·CBM: 7월 Quick Win → 8월 P0·P1 해소 → 9월 P2·P3 해소·검증 50% → 10~12월 확장.

03
Risk리스크 등록

P0 파츠 CBM 미등록으로 PropagationLedger 완결률 9% — 입하예측 신뢰도 저하. BOM 검증 완료율 6.9%로 구성 오류 리스크. 두 이니셔티브 모두 윤지수 1인 집중으로 Key Person Risk 존재.

04
Financial재무 영향

CBM 기반 차량 bin-packing 자동화(A1 Wave)로 차량이용률 KPI 개선 → 운임 단가 최적화. M/H 기반 인원 배치 자동화(WMS Phase 3)로 투입 인건비 효율화. 구체적 수치는 Phase 진행 후 KPI 리포트(SK-06)로 산출 예정.
