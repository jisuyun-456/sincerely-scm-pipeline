## 3. 안건별 논의 및 의사결정 (Key Discussions & Decisions)

### 안건 1: WMS Cycle-Time M/H 이니셔티브 Phase 1 완료 확인 및 Phase 2 착수 계획

- **논의 배경:**
  기존 CBM 추정 기반 M/H(Man-Hour) 산정 방식은 PT코드별 작업 특성 차이를 반영하지 못해 인원 배치 정확도가 낮았음. 이를 개선하기 위해 실측 cycle-time 기반 PT코드별 표준 M/H 전환 이니셔티브를 2026년 3월부터 착수하였으며, Phase 1(인프라 구축, 3~6월)이 완료됨.

- **의사결정 결과:**
  Phase 1 완료 공식 확인. Phase 2(표준 확정, 7~9월)를 2026년 7월부터 착수하기로 결정. 운영 즉시 적용 가능한 PT코드 3개에 대한 선행 운영 적용 검토 진행.

- **결정 근거 / 기대 효과:**
  Phase 1 완료 조건(1,000건 이상 누적)을 2,381건으로 초과 달성하여 통계적 신뢰성 확보. Phase 2 목표인 표준 M/H 모델(M/H = setup + qty × rate) 확정을 통해 2026년 9월까지 Top 20 PT코드 운영 기준(입하량 ~70% 커버)을 확립하고, 장기적으로 2026년 12월 M/H 기반 인원 배치 자동화 파일럿(Phase 3)으로 연결 예정.

### 안건 2: BOM·CBM 수량전파 백본 Phase 1 완료 확인 및 하반기 로드맵 공유

- **논의 배경:**
  Project → Order → Task → PKG → Movement → TMS 6개 모듈 간 자재·패키징 수량 연결이 수동으로 이루어져 오류 및 누락이 발생하였음. 이를 자동화하기 위한 BOM·CBM 수량전파 백본이 2026년 6월 12일 Phase 1 완료됨. 그러나 파츠 CBM 미등록 등 4개의 취약점이 잔존하여 하반기 해소 계획 수립이 필요한 상황.

- **의사결정 결과:**
  Phase 1 완료 공식 확인. 즉시 가동 가능한 6개 기능(A2 이송단가 정산, A3 차량적재율 KPI, A4 발송모드 분기, B3 입하예측, C2 패키징소요, D1 출하CBM 사전예측)에 대한 운영 시작 일정을 7월 Quick Win으로 지정. P0 취약점(파츠 CBM 미등록) 해소를 8월 최우선 과제로 설정.

- **결정 근거 / 기대 효과:**
  굿즈 CBM 커버리지 89.2%로 목표(80%)를 초과 달성하였으며, Cron 자동화(1일 3회)가 이미 가동 중임. 추가 개발 불필요한 기능 6건을 즉시 운영하여 CBM 기반 Wave 배차 최적화 및 MRP 자동산출 가치를 하반기 실현. 하반기 로드맵 이행을 통해 2026년 12월까지 원가분석, 완전주문 파일럿, Lane 수익성, ABC 분석으로 확장 예정.
