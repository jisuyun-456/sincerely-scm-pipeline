# 26년 7월 전략아이디어 — 아이디어4 (운영·Zerowaste)

**작성자:** 물류파트 윤지수 · **테마:** 4. 운영 — Zerowaste (반복업무 시스템화, 조직 생산성 50% 향상)

---

## 아이디어4

**[문제상황]**
프로젝트 등록→발주→생산·임가공→패키징→자재투입→배송(TMS)까지 이어지는 물류 현장 6단계가 프로젝트코드·아이템코드·파츠코드 같은 텍스트 키로만 위태롭게 연결돼 있다. 이를 잇는 기준 데이터인 BOM(자재명세) 마스터는 아예 없고 CBM(부피) 마스터도 반쪽만 존재해, 담당자가 매 프로젝트마다 자재소요·부피·배차·운임을 수기로 반복 계산한다.

**[아이디어]**
보령 프로젝트(PNA51684)처럼 여러 품목이 한 번에 발주될 때, BOM·CBM 데이터만 갖추면 프로젝트 등록 시점에 자재 수요예측·입하검수·창고 Capa·차량배차·운임산정이 한 번에 이어져 계산된다. 반복 수기계산을 데이터가 대신하면 신제품 제작일정이 더 빠르고 정확해지는 동시에, 담당자는 예외상황·의사결정에 집중할 수 있어 조직 생산성 향상에 기여한다.
