# CBM 백본 P0(안전)+P1(결정론 출고) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 추정 CBM이 실측 SSOT를 오염시키지 못하게 막고(P0), 출고 shipment CBM을 이름-퍼지가 아닌 결정론 견적코드 조인으로 채워 resolvable 15.8%→≥70% 달성(P1).

**Architecture:** 소스(⚡미러/MES/SERPA) read-only, 쓰기는 WMS_* 네이티브 + TMS Shipment 자동화 필드(`estimated_cbm`)만. 추정→`estimated_cbm`, 실측→`Total_CBM` 분리. 결정론 조인 = `Shipment.project code(PNA)` → 사전그룹 order rows → `order.굿즈코드` → `Product[견적코드]` CBM. 1출하 프로젝트만 기록, 다차는 partial_skip.

**Tech Stack:** Python 3.14, pytest, urllib/requests, Airtable REST. spec: `docs/superpowers/specs/2026-06-09-cbm-capacity-backbone-design.md`.

**환경:** `.env`에 `AIRTABLE_PAT`(TMS), `AIRTABLE_WMS_PAT`(WMS). 테이블: TMS `app4x70a8mOrIKsMf`(Shipment `tbllg1JoHclGYer7m`, Product `tblBNh6oGDlTKGrdQ`), WMS `appLui4ZR5HWcQRri`(order `tblJslWg8sYEdCkXw`).

```python
def _resolve_dup(a: dict, b: dict) -> dict:
    """중복 견적코드 결정론 해소: formula CBM>0 우선 → 큰 qty_per_box → rec_id 사전순."""
    for x, y in [(a, b), (b, a)]:

            return x
    if a["qty_per_box"] != b["qty_per_box"]:
        return a if a["qty_per_box"] > b["qty_per_box"] else b
    return a if a["rec_id"] <= b["rec_id"] else b
```

```python
def resolve_goods_code(row: dict) -> tuple[str | None, str]:
    """order/shipment row → (견적코드, 출처). 우선순위: order.굿즈코드 → (향후 pkg_schedule/crosswalk) → None.
    Returns (code_upper, 'direct'|'none')."""
    raw = row.get("굿즈코드 (from sync_itemdb)")
    if isinstance(raw, list):
        raw = raw[0] if raw else ""
    code = str(raw or "").strip().upper()
    if code:
        return code, "direct"
    return None, "none"
```

```python
def estimate_shipment_cbm_deterministic(
    project_code: str,
    order_by_project: dict[str, list[tuple[str, float]]],
    lookup: dict,
    shipment_count: dict[str, int],
) -> dict:
    """결정론 출고 CBM. order.굿즈코드→Product[견적코드]→ceil(qty/qpb)*cbm. 퍼지 없음.
    다차 출하 프로젝트는 partial_skip(중복합산 방지). 1출하만 기록."""
    import math as _m
    if shipment_count.get(project_code, 0) > 1:
        return {"estimated_cbm": 0.0, "confidence": 0.0, "mode": "partial_skip",
                "matched": [], "unmatched": []}
    lines = order_by_project.get(project_code)
    if not lines:
        return {"estimated_cbm": 0.0, "confidence": 0.0, "mode": "no_order",
                "matched": [], "unmatched": []}
    total = 0.0; matched = []; unmatched = []
    for code, qty in lines:
        e = lookup.get(str(code).lower())
        if e and e["cbm_per_box"] > 0 and qty > 0:
            boxes = _m.ceil(qty / e["qty_per_box"])
            total += boxes * e["cbm_per_box"]
            matched.append(code)
        else:
            unmatched.append(code)
    conf = 1.0 if matched and not unmatched else (0.7 if matched else 0.0)
    return {"estimated_cbm": round(total, 4), "confidence": conf,
            "mode": "deterministic", "matched": matched, "unmatched": unmatched}
```
