## Context

본 분석은 **(1) 2026 생산운영팀 전략문서 (Gamma)**에 명시된 재무 KPI와 **(2) 2026-05-19 물류파트 이니셔티브 회의** 결정 사항(M/H 측정 Iter 2.x)을 결합하여, *물류팀이 6~36개월 내 착수할 수 있는 전략 프로젝트 후보군 + 우선순위*를 도출한다.

**Why now:**
- 모기업 CRVS 영업이익률 **3.27%** — 미세 원가 변동이 흑자/적자를 결정
- SCRW 완전자본잠식 (순자산 -1.15억) + 단기대여금 7.2억 (+5.8억 YoY) — 단순 영업이익 개선이 아니라 **재무구조 회복**이 시급
- "금융부채 → 선수금" 자산 전환 = 1달 내 납품 입증 자료 자동화 필요 → **물류팀의 출고·POD 데이터가 재무 분류 enabler**

**Intended outcome:**
- Top 5 우선과제 확정 → 각 후보의 별도 spec 사이클(brainstorming → writing-plans → implementation) 진입 가능
- 회사 명시 KPI 5개 + 신규 KPI 5개 = **통합 KPI 셋 10개** 운영 시작
- H1 (6개월) 완료 시 SCRW 자본잠식 해소 범위(1.15억 보전) 진입 + 영업이익률 +0.5~1.0%p

## 1. 분석 프레임

### 1.1 회사 우선원칙 → 분석 제약

| 회사 원칙 | 분석 제약 |
|----------|---------|
| 재무 KPI 선수립 | 결과물 = "KPI + 이를 충족하는 후보들 + 왜 그 매핑인가" |
| AX/DX Scope 사전 확정 | 각 후보에 "성공의 정의" + "out of scope" + Kill criteria 명시 |
| 매몰비용 차단 | 모든 후보에 Reversibility 점수 + Kill criteria |
| 수평 생산성 +50% | 동일 물량을 1/2 MH로 처리 (Lean 해석, 인력 감축이 아닌 비목 전환) |

### 1.2 3H × Operating Leverage 하이브리드

- **축 1 시간**: H1 (0-6m) → H2 (6-18m) → H3 (18-36m)
- **축 2 비목**: 인건비 ↓ ↔ 수수료 ↑ ↔ CapEx/임차 ↔ OpEx 전환
- **축 3 도메인**: WMS / TMS / Cross-cutting

### 1.3 핵심 가정

- G1 ✅ 외주 ₩ 분리 가능 (슬라이드에 지급수수료/지급임차료 별도 비목 존재)
- G2 ⚠️ M/H 정밀도는 Iter 2.x 완료에 종속 (회의록 A1~A5 완료 후 갱신)
- G3 ✅ 매출 ±15% 가정 (포장재 산업 변동성)
- G4 ✅ 생산성 50% = "동일 물량을 1/2 MH" (슬라이드 표현 정합)
- G5 ✅ AX/DX = AI 자동화 + 디지털화 + 외주 재배분 (사용자 합의)
- H1 ⚠️ SCRW 단독 매출 규모 미공개 → CRVS 193.9억 기준으로 진행, SCRW 환산은 추후
- H2 ⚠️ 외주 3종(임가공·보관·풀필먼트) 월간 ₩ 분포 미확정 → W-H1-04에서 추출
- H3 ⚠️ 제조노무원가 내 물류 비중 미확정 → X-H1-01에서 확인
